Сборка и публикация документации¶

Повторная сборка¶

Готовый сайт хранится в docs/site. Для регенерации нужен Python 3.12+ и зависимости приложений: экспорт импортирует настоящие FastAPI-приложения, а ML при импорте загружает свои артефакты. Обучение и lifespan не запускаются.

Из корня репозитория, в отдельном Python-окружении:

python -m pip install -r docs/requirements.txt -r backend/requirements.txt -r ml_service/requirements.txt
python docs/build.py

Сборка заново извлекает сигнатуры и поля из Python AST, экспортирует OpenAPI Backend и ML в отдельных процессах (оба используют пакет с именем app), проверяет Swagger и /health через ASGI без открытия сетевых портов, затем запускает Sphinx с ошибкой при любом предупреждении. Справочник генерируется из кода без запуска функций; это Sphinx-документация, не вручную переписанный перечень сигнатур.

docs/generated и docs/openapi обновляются сборкой. Их, а также docs/site, следует коммитить вместе с изменениями контрактов. Пояснения к модулям находятся в docs/module_descriptions.json. Редактируйте исходные .rst и описания, а не готовые HTML-файлы.

Что передать в форме хакатона¶

Можно передать ссылку на docs/README.md в опубликованной ветке репозитория: там есть инструкция открытия готового сайта и ссылки на обе OpenAPI-схемы. Доступ к репозиторию должен быть предоставлен жюри.

Для удобного просмотра без скачивания опубликуйте папку docs на статическом хостинге. Например, в GitHub Pages выберите ветку с этой документацией и каталог /docs; docs/index.html перенаправляет на site/index.html. Файл .nojekyll сохраняет служебные каталоги Sphinx. Доступность Pages зависит от настроек и тарифа репозитория. После публикации проверьте фактический адрес в браузере и передайте его жюри. Само наличие HTML в репозитории ещё не означает, что сайт опубликован. Порядок настройки: официальная инструкция GitHub Pages.

Статический Swagger предназначен для чтения схем: выполнение запросов отключено. Для запросов используйте Swagger запущенных сервисов. Публикация сайта документации не публикует Backend или ML и не делает localhost удалённо доступным.
