Запуск и проверка¶

Готовая документация¶

Откройте docs/site/index.html в браузере. Для просмотра страниц и поиска не нужны Python, Docker или работающий ML. Встроенные страницы Swagger используют ресурсы CDN и требуют интернета; JSON-схемы доступны локально.

Документацию также можно обслуживать отдельным контейнером, из корня проекта:

docker compose -f compose.docs.yaml up -d

Адрес: http://localhost:8082. Эта команда запускает только готовую документацию.

Рабочая система¶

При наличии архива эмулятора организаторов:

docker load -i ndtp-telemetry-emulator.tar
docker compose up --build -d

Без архива, для исторического режима и внешнего NDTP:

docker compose -f compose.history.yaml up --build -d

  • Дашборд: http://localhost:8080.

  • Swagger Backend: http://localhost:8000/docs.

  • Swagger ML: http://localhost:8001/docs.

  • Альтернативное представление API: /redoc на каждом сервисе.

  • NDTP: TCP-порт 9201, не HTTP.

В Compose HTTP-порты Backend и ML привязаны к 127.0.0.1. Эти адреса предназначены для машины, на которой запущен проект. localhost не является публичным адресом команды.

Пробный запрос в Swagger¶

Откройте Backend Swagger, раскройте GET /health, нажмите Try it out, затем Execute. Ожидается HTTP 200 и {"status": "ok"}. Повторите для ML. Это проверка HTTP-сервисов, а не качества прогнозов.

Для проверки всего пути данных откройте дашборд и выберите «Тестовые данные». Backend запускает расчёт через ML; GET /api/v1/replay показывает состояние, число обработанных точек и результаты. При штатном завершении state равно complete. В комплекте validate содержится 151 точка.

Для живого потока выберите «Эмулятор NDTP». Проверяйте GET /api/v1/ndtp/status и GET /api/v1/fleet. Приём GPS не означает наличие условий для прогноза: необходимы актуальное расписание, соответствие устройства рейсу и отклонение.

Если прогнозов нет¶

  • /health недоступен: проверьте запуск и логи соответствующего контейнера.

  • replay.state = failed: изучите error; проверьте ML и входные CSV.

  • GPS есть, прогнозов нет: проверьте целевую остановку в окне (10, 15] минут, координаты остановки и текущее отклонение от графика.

  • План из репозитория относится к 6–7 января 2026 года. Он не подходит автоматически для живого потока с сегодняшней датой.
