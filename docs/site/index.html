Документация Metrohack¶

Система принимает транспортную телеметрию, сопоставляет её с расписанием и прогнозирует задержку на целевой остановке в окне (10, 15] минут. Этот сайт объединяет сгенерированный Sphinx-справочник Python-кода и спецификации OpenAPI двух сервисов; это материалы для пункта 4 сдачи хакатона.

Начните с Запуск и проверка. Для изучения реализации откройте Архитектура и модули и Справочник Python-кода. Контракты запросов находятся в HTTP API и Swagger.

Границы документации¶

Справочник охватывает Python-модули Backend и ML, вспомогательный скрипт NDTP и запуск обучения. Vue-фронтенд описан на уровне архитектуры и обмена данными. Ноутбуки, сторонние библиотеки и тесты не включены в справочник функций. Сигнатуры и поля извлекаются из исходников автоматически; пояснения к подсистемам подготовлены отдельно. Экспорт OpenAPI не запускает TCP-приёмник и не обучает модели.
